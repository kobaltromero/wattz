### 0.1.0-beta.2 - September 14th, 2026
- Renamed AlternatorTier record to Tier.Alternator in preparation for addition of other contraptions. -kobaltromero
- Fixed Voltaic's wrench not allowing rotation on all available axis like Create's wrench does. -kobaltromero
- Fixed weird Alternator drop behavior when using wrenches. -kobaltromero
- Fixed Z-Fighting on Alternator Models. (Flashing textures) -kobaltromero
- Fixed Ponder scene not rendering Alternator Block. -kobaltromero
- Fixed alternators outputting electricity from all sides. This behavior was not intentional. A minor oversight, but an annoying one on my part. Electricity should only get output from the side with the output. -kobaltromero
- Added support for Voltaic's Stator Upgrades. Right click with a stator upgrade to insert and shift right click to remove it. (Default is 10% but has a configurable range between 0-100%) -kobaltromero
- New default config values courtesy of korobeinick in the Electrodynamics Discord. -kobaltromero
- Implemented in game configuration. -kobaltromero
